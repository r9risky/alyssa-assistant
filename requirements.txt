# Plays her TTS audio. Used instead of playsound because pygame.mixer.music
# can be stopped mid-playback (playsound can't), which is what lets you
# interrupt her by talking - see ALLOW_INTERRUPTIONS in config.py.
# Using pygame-ce (Community Edition) instead of plain "pygame": same
# "import pygame" name and the same mixer.music API voice.py uses, but it
# actually ships prebuilt wheels for current Python versions. Plain pygame's
# last release (2.6.1) has no wheel for newer Pythons, so pip falls back to
# compiling it from source - which fails on current setuptools because that
# old build script needs distutils.msvccompiler, removed in setuptools 80+.
pygame-ce

# file with keyword-overlap matching instead of a vector database - see
# memory.py's docstring and the "Saved memory storage" section of
# README.md for what changed and why. This removes the chromadb +
# onnxruntime dependencies and the ~90MB embedding model download that
# used to live here, in exchange for losing true zero-shared-word
# semantic matching (a fairly rare case in practice at this scale).

# nvidia-cuda-runtime-cu12) lives in requirements-gpu.txt, not here -
# start_alyssa.bat only installs that file when config.py's
# WHISPER_DEVICE is "auto" or "cuda", skipping several GB entirely on a
# WHISPER_DEVICE = "cpu" setup like the default in this config.py.
